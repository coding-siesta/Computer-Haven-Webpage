# Computer-Haven
A website for computer peripherals built with HTML, CSS, and JavaScript

## About
Computer Haven is a transactional website that allows user to browse and order computer peripherals online. Built as a school project using HTML, CSS, and JavaScript

## Features
- Browse computer peripherals
- Add items to cart
- Place and manage orders
